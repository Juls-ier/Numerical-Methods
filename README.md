# Numerical-Methods
A collection of numerical algorithms implemented in C++ as part of computational engineering coursework and personal learning.

The main goal of the project was to understand the mathematical foundations of the methods and implement them from scratch

# Topics Covered

## Interpolation

Lagrange interpolation

Newton interpolation

Divided differences

Polynomial interpolation and numerical stability

Runge phenomenon

## Systems of Linear Equations

Gaussian elimination

Gaussian elimination with partial pivoting

Gaussian elimination with column pivoting

LU decomposition

Iterative Jacobi method

Diagonal dominance analysis

## Numerical Integration

Midpoint rectangle rule

Trapezoidal rule

Simpson's rule

Gaussian quadrature

Comparison with analytical solutions

## Numerical Solutions of ODEs

Euler method

Runge-Kutta 2nd order (RK2)

Runge-Kutta 4th order (RK4)

Comparison of numerical and analytical solutions

## Approximation

Least-squares polynomial approximation

Weighted approximation

Orthogonal polynomial approximation

Three-term recurrence relation

Approximation error functional

## Nonlinear Equations

Bisection method

Regula Falsi (False Position)

Secant method

Newton's method
